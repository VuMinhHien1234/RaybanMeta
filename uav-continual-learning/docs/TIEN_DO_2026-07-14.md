## 2. Vừa làm gì (theo thứ tự trong phiên)

**a. G2 — bộ nhớ Titans xuyên task (code trọn bậc A/B/C).** 4 file lõi:
`state_utils.py` (detach/clone/norm/save state — chống phụ thuộc version thư viện),
`memory.py` (TitansMemory, API cố định `(seq, state) → (out, state)`),
`seq_adapter.py` (ảnh→chuỗi: image_seq/token_seq), `titans_head.py` (TitansClassifier,
3 chế độ `reset: image|task|never` + 2 luật an toàn: truncated BPTT detach mỗi batch;
eval xuất phát từ clone state — "chấm thi không ghi trí nhớ"). Method `titans` quản lý
vòng đời state + log norm(state) mỗi task. 3 config + 5 test.

**b. M3 optimizer — cài từ công thức gốc.** Đọc Algorithm 1 (§7.2) + Eq. 75 trực tiếp từ
NL.pdf: 2 tầng ký ức gradient (nhanh mỗi bước, chậm gộp f bước) + Newton–Schulz kiểu Muon
+ chia √V kiểu Adam. Nối vào engine qua `train.optimizer: adamw|m3`; run M3/AdamW lưu
thư mục riêng, bảng so sánh thêm cột optimizer. **M3 là mặc định** mọi config G2/G3.

**c. Delta Momentum (Eq. 48–49) — chế độ chuẩn của M3.** `beta_style: delta`:
`M ← α·M + η·(g − M)` — chỉ ghi phần sai lệch, cổng quên α tách riêng tốc độ ghi η.
Ghi chú trung thực trong docstring: đây là Eq. 49 với key hằng (bản key-ma-trận đầy đủ
bất khả thi cho optimizer trên trọng số); α=1 thì trùng EMA (có test chứng minh bằng
quỹ đạo y hệt). Chuỗi ablation 3 nấc sẵn sàng: paper → ema → delta.

**d. G3 — CMS retrofit (code trọn).** `cms_optimizer.py` (tier chậm p bước mới update,
grad trung bình, η per-tier — bọc được cả M3 lẫn AdamW), `models/cms.py` (chia 12 block
ViT theo `order: late_slow|early_slow`; attention+norm vào tier chậm nhất theo quyết định
team, có đường lùi `attn: freeze`; nền pretrained đóng băng; head tier nhanh; `tier_report`
kiểm bằng mắt), method `cms` log ‖Δw‖ per-tier (bằng chứng cơ chế + máy dò bug). 2 config
+ 6 test (có test số CHÍNH XÁC bằng SGD lr=1).

**e. Kế hoạch G4** (`plans/TASKS_G4_SOLO.md`) theo 4 quyết định đã chốt: HOPE nối tiếp
feature-level; η adaptive làm sau HOPE-fixed; ablation 2×2 + thành phần; code wiring ngay.
M3 vốn là việc nặng nhất G4 đã xong trước → G4 còn ~3 tuần.

**f. Sửa 2 bug:** numpy 2.x (`np.trapz` bị xoá — lỗi getattr đánh giá sớm) và
`compare_g1.py` thiếu tabulate (thêm fallback + xuất CSV + thêm vào requirements).

- Chống quên hiện phủ **3 tầng**: delta-rule trong Titans memory (đặc trưng) · CMS đa tần số
